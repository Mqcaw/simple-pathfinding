# Simple a* pathfinding prpgram implemented in C using SDL2

When I first made this I was only focused on functionallity. There are bugs and proformace issues.

## Installation

```
git clone https://github.com/Mqcaw/simple-pathfinding.git
cd simple-pathfinding
.\build.bat
```
Or simply run the precompiled executable in `src/bin/main.exe`

## Controls
`left click/drag` - Place walls\
`ctrl + left click` - Place start cell\
`ctrl + right click` - Place end cell\
`right arrow` - Run pathfinding\
`space` - Play/puase continual solving\
`c` - Clears grid\
`m` - Clears grid and generates a random maze\
